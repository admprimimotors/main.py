Configurar cookies de ML

ML no expone el endpoint del historial en su API pública. Lo scrapeamos del seller hub web, y para eso necesitamos las cookies de tu sesión.

📖 Cómo obtener las cookies (1 minuto)
  1. Abrí mercadolibre.com.ar en Chrome (logueado como Primi Motors).
  2. Tocá F12 para abrir DevTools.
  3. Andá a la pestaña Network.
  4. Click derecho sobre cualquier request → Copy → Copy as cURL.
  5. Pegá acá abajo el cURL completo, o
  6. Alternativa rápida: en DevTools → pestaña Application → Cookies → https://www.mercadolibre.com.ar → seleccioná todas con Ctrl+A → click derecho → Copy all as JSON → pegá acá.

💡 También funciona pegar el header crudo Cookie: name1=val1; name2=val2; ... que ves en la pestaña Network → Headers de cualquier request a mercadolibre.com.ar.
